# Christian Wijaya Luxury Fashion Website

A modern luxury fashion e-commerce website developed using HTML, CSS, and JavaScript. This project showcases an elegant online shopping experience featuring premium fashion products, brand storytelling, product details, shopping cart functionality, and promotional events.

## Features

* Responsive and modern user interface
* Luxury fashion branding design
* Featured Products section
* New Arrival Products section
* Product Detail Pages
* Shopping Cart functionality
* Event Promotion and Registration page
* Interactive navigation
* Product image gallery
* Video banner on homepage

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome

## Pages

### Home Page

Displays featured products, new arrivals, promotional campaigns, customer testimonials, and brand introduction.

### Product Page

Provides product listings and navigation to detailed product pages.

### Product Detail Page

Shows product information, images, pricing, variants, sizes, and purchase options.

### Event Page

Promotes exclusive Christian Wijaya fashion events and campaigns.

### About Us Page

Introduces the brand story and company vision.

### Cart Page

Allows users to manage selected products before checkout.

## Installation

1. Clone the repository

```bash
git clone https://github.com/chelseaolyvianii/christian-wijaya
```

2. Open the project folder

```bash
cd christian-wijaya
```

3. Run the website

Open `index.html` directly in your browser or use Live Server in Visual Studio Code.
